# Invitación Marina & Fernando

Invitación digital de casamiento para **Marina & Fernando**.

- [Civil y Conferencia](https://ger1211.github.io/casamiento-marina-fernando/)
- [Reunión íntima](https://ger1211.github.io/casamiento-marina-fernando/reunion.html)
- [Compartí tus fotos](https://ger1211.github.io/casamiento-marina-fernando/fotos.html)

Diseño en paleta **oliva + celeste pastel**, con hojas y flores en acuarela, y animaciones con **GSAP**.

El sitio es completamente estático y está pensado para publicarse en GitHub Pages.

## Página de fotos

`fotos.html` permite a los invitados subir y ver fotos del evento. Usa el backend
[photo-upload-service](https://github.com/Ger1211/photo-upload-service) (álbum `marina-fernando`).

- Para probar en local, `js/fotos.js` apunta al túnel de Tailscale (`API_BASE_URL`).
- El día del evento, cambiar `API_BASE_URL` en `js/fotos.js` a la URL del backend en la nube.

## Créditos

- Hojas de eucalipto y esquina floral: recursos gratuitos de [CleanPNG](https://www.cleanpng.com/).
- Fuentes: Google Fonts (Dancing Script, Cormorant Garamond, Jost).
- Animaciones: GSAP.
